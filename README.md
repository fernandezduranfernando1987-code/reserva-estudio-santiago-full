# Kodarvia - Reserva Estudio Santiago

## Cómo correr en local

npm install

npm run dev

## Ruta del panel admin

La ruta es /admin, el archivo es src/routes/admin.tsx y el componente de bloqueos es src/components/bloqueos-admin.tsx

## Datos de ejemplo

Las reservas de prueba y bloqueos se guardan en localStorage en kodarvia_reservas y kodarvia_bloqueos. Para reiniciar, borrar esas claves en DevTools > Application > Local Storage.

## Clave admin

ADMIN_PASSWORD en src/routes/admin.tsx, por defecto admin123
